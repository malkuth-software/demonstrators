# Demonstrators

Applications that exercise GUI.Forms under load, written against its public API only. Each one is a stress test and a worked example; the gaps it finds are fixed in GUI.Forms before 1.0.

| App | Folder | Status |
|---|---|---|
| Chat stress | `chat_stress/` | written, not yet built |
| Node graph | `node_graph/` | written, not yet built |
| ImGui-class widgets (D3) | `imgui_class/` | written, not yet built |
| ImPlot-class plots (D4) | `implot_class/` | written, not yet built |
